% Canonical table vocabulary. Rendered table sources use these labels so global
% term changes stay centralized.
%
% Contribution-role rule:
% Attack = paper primarily demonstrates an adversarial method or unsafe exploit.
% Defense = local technical detector, verifier, guard, mitigation, or repair.
% Governance = lifecycle policy, control plane, audit, authorization, recovery,
% and accountability coordination across multiple controls.
% Benchmark = reusable task suite, protocol, sample set, or denominator.
% Safety = diagnostic or measurement work whose main contribution is exposing a
% hazard, drift, leakage, or failure mode rather than attacking or defending it.
% Capability = architecture, algorithm, system, or substrate mechanism used to
% explain reusable state, without being primarily safety work.
% Survey = literature synthesis or review. Survey subtypes describe the
% contribution function, not the research object: use Survey (Capability) for
% architecture/mechanism/lifecycle surveys, Survey (Safety) for safety,
% privacy, or governance-risk syntheses, and Survey (Attack) for threat or
% attack-family syntheses.
% Framework = external standard, formal framework, or conceptual security model;
% use Framework (Subtype) when the framework role is security, governance, or
% formalization-specific.
% Theory = foundational theory used for comparison.
% Red Team = adversarial testing where the primary artifact is a red-team
% procedure or evaluation rather than a reusable benchmark suite.
%
% Role-name rule:
% Literature-index tables use Role only for contribution/content type. Research
% objects such as LLM, Agent, Memory, Tool, Skill, Model, Workflow, or Multi-Agent
% state must live in Target/Object columns, not inside Role. When a coarse role
% needs a content subtype, render it as Role (Subtype), e.g.,
% Benchmark (Attack), Benchmark (Safety), Evaluation (Defense), or
% Framework (Governance). Security-oriented and cyber/misuse benchmarks use
% Benchmark (Attack), not a separate security-benchmark term.
%
% Visual grammar:
% Role terms use text color only. Target terms use a quiet sans-serif text style
% without background. Object and adaptation-operation terms use restrained
% rounded pills because they are short, repeated scan cues.
